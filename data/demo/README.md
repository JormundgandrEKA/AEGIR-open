# data/demo/

Sessions on the bundled demo batch (16 real ClinicalTrials.gov cases, in `../../demo/`) write here as `<your name>/` (`labels.jsonl`,
`notepad.jsonl`, `drafts.jsonl`, `sessions/`). They are kept apart from real labels in `data/labels/`, so demo work never enters
the tally or efficiency reports. This folder's contents are ignored by git except this file.

The location is the `demo_output_dir` setting in `config/aegir.json`.
